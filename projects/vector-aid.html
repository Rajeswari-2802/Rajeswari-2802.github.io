Vector Aid: clearing the road before the siren arrives.

A vehicle-to-vehicle RF system that lets an ambulance tell the vehicles ahead where it is, where it's heading and which route it will take, so drivers can make way early instead of reacting at the last second.

TypeTeam → Final Year Project
PlatformRaspberry Pi 4 Model B
LinknRF24L01 · 2.4 GHz RF
DomainV2V · Smart mobility
Fig. 1: Ambulance node fuses GPS, heading and route data, then broadcasts it to vehicle units over RF.

The problem

In dense city traffic, a siren is heard late and gives no direction. Drivers can't tell whether the ambulance is behind them, crossing ahead or taking another road, so lanes clear slowly and unpredictably.

Every minute lost in transit matters for emergency patients.

The idea

Give the ambulance a digital voice. Instead of relying on sound, it broadcasts its live position, heading and planned route directly to nearby vehicles over a short-range RF link, and each vehicle unit decides whether to alert its driver.

How it works

LocateThe NEO-M8N GPS module provides live position and speed on the ambulance node.
OrientAn MPU6050 motion sensor supplies heading so direction of travel is known.
RouteOpenRouteService returns the ambulance's planned path to its destination.
BroadcastThe Raspberry Pi packages the data and transmits it over nRF24L01 to receiver units in range.

Hardware stack

Raspberry Pi 4Model B, 4 GB. One board per node (transmitter and receiver)
nRF24L012.4 GHz RF transceiver with base board for the V2V link
NEO-M8NGNSS module for position and speed
MPU6050IMU (HW-123 board) for heading
OpenRouteServiceRouting API for the ambulance's planned path

Engineering decisions

  • Direct RF, not cloud: the alert travels vehicle-to-vehicle, so it keeps working where mobile data is weak.
  • Raspberry Pi 4 over a bare MCU: enough compute to handle GPS parsing, routing data and radio on one board, with room to grow into a product-level build.
  • Route-aware alerts: sharing the planned path, not just position, lets receivers judge whether the ambulance is actually coming their way.

My journey with it

Vector Aid began as a group project. After that first build it became my final-year project, and it has grown into the Raspberry Pi 4 based system described here.

Built as a team. Tools used: Raspberry Pi 4 Model B, nRF24L01, NEO-M8N GPS, MPU6050, Python, OpenRouteService API.
